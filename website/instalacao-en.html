Installation

The security warnings below are expected: they do not mean anything is wrong, and they only appear the first time. The app does not carry Microsoft's or Apple's paid signature.

Windows

  1. Download batruc-0.1.5-windows-x64.exe and open it.
  2. Windows shows “Windows protected your PC”: click “More info”, then “Run anyway”. If asked for administrator permission, click “Yes”.
  3. Click “Next” to the end. Batruc is then in the Start menu.
  4. Without installing: unzip the .zip and open Batruc.exe.

macOS (Intel and Apple Silicon, 10.15 or newer)

  1. Download batruc-0.1.5-macos-universal.dmg, open it and drag Batruc into Applications.
  2. On first launch macOS blocks the app (“Apple could not verify…”). Click “OK” or “Done”, not “Move to Trash”.
  3. Allow it once: System Settings → Privacy & Security → “Open Anyway”. On macOS 14 or earlier: right-click the app → “Open” → “Open”.
  4. If the button does not appear, run this in Terminal (no output means it worked):
xattr -dr com.apple.quarantine "/Applications/Batruc.app"

Linux (x86-64, glibc 2.35 or newer)

  • Ubuntu, Debian and Mint: double-click the .deb, or sudo apt install ./batruc-0.1.5-linux-x86_64.deb.
  • Other distributions: the AppImage (make it executable and open it) or the .tar.gz (unpack it and run ./install.sh, which installs into ~/.local without root).
  • Launch-tested on Debian 12, Ubuntu 24.04, Fedora and Arch.

Where things live

  • Scenes (.batruc.txt), WAV recordings and MusicXML: in the folder you choose when saving.
  • Preferences: ~/.config/RASGO/Batruc.settings on Linux; the equivalent system folder on Windows and macOS.
  • The Rhythms / MIDI catalogue (Groove MIDI Dataset, CC BY 4.0) ships inside the package, with its licence.

Windows and macOS are built and tested by continuous integration but have not yet been opened on real machines. If something does not open, write to the contact below with your system version and the message you see.
