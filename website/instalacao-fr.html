Installation

Les avertissements de sécurité ci-dessous sont attendus : ils ne signalent ni défaut ni virus et n'apparaissent que la première fois. L'app n'a pas la signature payante de Microsoft ni d'Apple.

Windows

  1. Téléchargez batruc-0.1.5-windows-x64.exe et ouvrez-le.
  2. Windows affiche « Windows a protégé votre ordinateur » : cliquez sur « Informations complémentaires », puis « Exécuter quand même ». S'il demande l'autorisation d'administrateur, cliquez sur « Oui ».
  3. Cliquez sur « Suivant » jusqu'à la fin. Batruc est alors dans le menu Démarrer.
  4. Sans installer : décompressez le .zip et ouvrez Batruc.exe.

macOS (Intel et Apple Silicon, 10.15 ou plus récent)

  1. Téléchargez batruc-0.1.5-macos-universal.dmg, ouvrez-le et glissez Batruc dans Applications.
  2. À la première ouverture, macOS bloque l'app (« Apple n'a pas pu confirmer… »). Cliquez sur « OK » ou « Terminé », pas sur « Placer dans la corbeille ».
  3. Autorisez-la une fois : Réglages Système → Confidentialité et sécurité → « Ouvrir quand même ». Sous macOS 14 ou antérieur : clic droit sur l'app → « Ouvrir » → « Ouvrir ».
  4. Si le bouton n'apparaît pas, lancez ceci dans le Terminal (aucune réponse = réussi) :
xattr -dr com.apple.quarantine "/Applications/Batruc.app"

Linux (x86-64, glibc 2.35 ou plus récente)

  • Ubuntu, Debian et Mint : double-cliquez sur le .deb, ou sudo apt install ./batruc-0.1.5-linux-x86_64.deb.
  • Autres distributions : l'AppImage (rendez-la exécutable et ouvrez-la) ou le .tar.gz (décompressez-le et lancez ./install.sh, qui installe dans ~/.local, sans root).
  • Ouverture testée sous Debian 12, Ubuntu 24.04, Fedora et Arch.

Où sont les choses

  • Scènes (.batruc.txt), enregistrements WAV et MusicXML : dans le dossier choisi à l'enregistrement.
  • Préférences : ~/.config/RASGO/Batruc.settings sous Linux ; le dossier système équivalent sous Windows et macOS.
  • Le catalogue Rythmes / MIDI (Groove MIDI Dataset, CC BY 4.0) est inclus dans le paquet, avec sa licence.

Windows et macOS sont compilés et testés par l'intégration continue mais n'ont pas encore été ouverts sur de vraies machines. Si quelque chose ne s'ouvre pas, écrivez au contact ci-dessous avec la version du système et le message affiché.
